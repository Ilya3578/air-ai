Air-AI — приложение с поиском рейса из Пулково

ПРОСТОЙ ЗАПУСК НА WINDOWS
1. Распакуйте весь ZIP-архив в отдельную папку.
2. Если Node.js не установлен, установите Node.js LTS: https://nodejs.org/
3. Дважды нажмите start_air_ai.bat.
4. Откроется браузер с Air-AI. Окно консоли не закрывайте, пока пользуетесь приложением.

В состав входят:
- Air-AI_version7_local_AI.html — интерфейс приложения
- server.js — локальный сервер и обработчик поиска
- package.json — зависимости
- start_air_ai.bat — запуск двойным нажатием в Windows

Поиск: сначала официальный сайт Пулково, затем публичный источник PocketWorld. Если доступно, дополнительные данные самолёта запрашиваются у ADS-B.lol.

ОГРАНИЧЕНИЯ
Для поиска требуется интернет. Источники могут менять формат и не всегда предоставляют расписание/время прилёта/стойку/гейт. Данные, которых нет в источнике, не подставляются. В этой среде не удалось проверить живые ответы источников, поэтому актуальность данных в реальном запуске не гарантируется.
